# AI project context

Structured context and actionable issue records for AI-assisted development. Durable public or developer documentation belongs in `docs`.

Store one issue per Markdown file. Distinguish confirmed facts from inferences, update existing issues instead of duplicating them, and do not mark an issue resolved until its acceptance criteria are verified. `services/api/prisma/schema.prisma` is the canonical database schema and `services/api/prisma/migrations` is the canonical migration history.
